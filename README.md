# Customer Management System

A MERN Stack Customer Management System with JWT Authentication.

## Features

- Login & Registration
- Dashboard
- Customer CRUD
- Search & Filter
- MongoDB Atlas
- Responsive UI

## Tech Stack

- React (Vite)
- Node.js
- Express.js
- MongoDB Atlas
- JWT
- Mongoose

## Installation

### Backend

```bash
cd Backend
npm install
npm run dev
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```
